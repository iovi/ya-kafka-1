Проверялось на windows11 c установленным docker desktop
Для работы необходим работающий docker и java 17

Для запуска кластера Kafka необходимо в папке с docker-compose.yml выполнить
>docker-compose up -d

Для запуска приложения необходимо запустить приложенный в out/artifacts/ya_kafka_1_jar/ya-kafka-1.jar файл jar 
>java -jar ya-kafka-1.jar
Запустить его можно множество раз для одновременной работы нескольких экземпляров приложения. Также можно запустить в среде разработки 

В приложении реализованы 
* продюсер RandomMessageProducer - каждые 2 секунды генерирует, выводит в консоль и отправляет новое сообщение со случайными данными.
* консьюмер SingleMessageConsumer - каждую секунду вычитывает по одному сообщению, выводит в консоль и коммитит offset
* консьюмер BatchMessageConsumer - каждые 10 секунд вычитывает минимум по 10 сообщений, если их за это время меньше  - ничего не делает, если не меньше - выводит все в консоль и применяет offset.
